# 罗睿 / Pumpkin — 个人作品集

React + Vite 单页作品集，当前为本地预览基础版。

## 启动

Windows 可双击 `启动预览.cmd`，然后打开终端显示的本地地址。

也可在本目录执行：

```sh
pnpm install
pnpm dev
```

生产构建：`pnpm build`，输出至 `dist/`。当前未部署到互联网。

## 已包含

- 两段真实视频与两段反向转场视频组成三幕首页；转场已预处理为适合实时播放的短片，一次滚轮手势切换一幕，正向与回看均有完整动画，刷新自动回到初始画面。
- 橙黄、亮橙、藏蓝、紫罗兰与淡紫蓝构成的 WebGL 流体渐变，约 1700px 内容版心；页面、首页视频和弹窗均带较小范围的鼠标折射及滚动惯性。
- 五个全宽横向作品类别卡片，共 17 个项目、197 张图片；画面占约三分之二，项目入口集中在磨砂信息区。
- 原生 dialog 项目弹窗带类似手机 App 的缩放、位移、模糊开合动画，支持独立滚动、Esc 关闭、关闭后恢复焦点与浏览位置。
- 案例图片按类别分别使用全宽、两列或三列排版；视觉项目的指定物料、海报横竖版、标志字体及两类 AI 项目均采用独立规则。
- GSAP + ScrollTrigger 遮罩揭示、错峰进场、轻微视差与压缩归位动效，向上回滚时反向收回。
- AI 协同项目、个人经历卡片、五项放大数据、六项能力与联系方式。
- 微信号复制，邮箱和电话链接。

## 内容维护

- `src/main.jsx`：页面内容、联系方式、经历与交互。
- `src/style.css`：配色、字体、布局和适配。
- `src/background.jsx`：动态渐变与视频 WebGL 水波形变。
- `src/motion.jsx`：GSAP 页面进场、错峰与视差动效。
- `src/projects.json`：项目资料、图片顺序和分组。
- `public/media/`：网页使用的压缩素材，不修改原始作品。
- `scripts/prepare-assets.mjs`：从上一级五个作品文件夹生成 WebP 和项目清单。
- `scripts/prepare-video.mjs`：生成适合滚动定位的视频与静帧。

重新导入素材：`pnpm prepare:assets`。脚本会同步新增、替换和删除生成目录中的项目素材，并重新生成项目清单；手动编辑清单前请保留副本，或同步修改导入脚本。

首页视频来自上一级“作品集首页”。原片首尾构图的差异保留在视频素材中；之后可更换更精细的转场视频。默认字体签名使用设备上的 Segoe Script，其他设备回退至手写字体；正式跨平台定稿时可换成已获授权的网页字体或矢量签名。
